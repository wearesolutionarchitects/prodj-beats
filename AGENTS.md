# Repository instructions

Read and follow [.github/copilot-instructions.md](.github/copilot-instructions.md)
before working in this repository. These project instructions apply to Codex
and other coding agents as well as GitHub Copilot.

In particular, the user owns the VS Code terminals running the dev server and
Java bridge together via `npm run dev`. Reuse those services; do not launch independent background servers.
